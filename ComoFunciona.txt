Id. Requerimiento: REQ001
Nombre del Requerimiento: Login
Clasificación o prioridad: 1

No. Func.	Funcionalidad
001	Permitirá el acceso a los usuarios.
002	Permitirá el ingreso a través de un correo electrónico.
003	Permitirá ingresar la contraseña del usuario, la cual será de tipo alfanumérica.
004	Se verificará el usuario, contraseña y estado en la base de datos.
005	En caso de incompatibilidad o error en los datos ingresados, se mostrará un mensaje de advertencia y se restablecerán los campos para intentar nuevamente.

Requisitos No Funcionales

ID	Categoría	Descripción
RNF001	Seguridad	El sistema debe encriptar las contraseñas y utilizar tokens JWT para la autenticación segura.
RNF002	Rendimiento	El sistema debe responder a las solicitudes de los usuarios en un tiempo máximo de 2 segundos.
RNF003	Disponibilidad	El sistema debe garantizar una disponibilidad del 99.9% durante el horario operativo logístico.
RNF004	Usabilidad	La interfaz web debe ser responsiva y adaptarse correctamente a dispositivos móviles, tablets y PCs.
RNF005	Escalabilidad	La arquitectura debe soportar un incremento en la cantidad de usuarios concurrentes y volumen de datos sin degradarse.
RNF006	Mantenibilidad	El código fuente debe seguir convenciones estrictas y estar modularizado para facilitar futuras actualizaciones.
RNF007	Compatibilidad	La aplicación debe funcionar correctamente en las versiones más recientes de Chrome, Firefox, Safari y Edge.
RNF008	Respaldos	El sistema de base de datos debe generar respaldos automáticos periódicos para evitar pérdidas de información.
